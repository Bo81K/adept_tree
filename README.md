# Дерево данных

Десктопное приложение для работы с древовидной структурой данных, хранящейся в локальной базе данных **PostgreSQL**. Каждый лист дерева содержит текстовое название и числовое значение с плавающей точкой.

## Реализованные возможности

* **Интерфейс:** отображение дерева на базе `QWidget`, статусная строка со статистикой (количество узлов и листьев, минимальное и максимальное значения).
* **Управление данными:** добавление, редактирование, переименование и удаление узлов и листьев (с каскадным удалением).
* **Фильтрация:** поиск листьев по названию (без учета регистра) и по числовому значению (поиск подстроки). Опциональный поиск по названиям родительских узлов.
* **Импорт и экспорт:** сохранение и загрузка дерева из файла в формате JSON.
* **Тестирование:** модульные тесты на `QTest` с использованием изолированной тестовой базы данных.

## Стек технологий

* **Язык:** C++17
* **Фреймворк:** Qt 5.15 (Widgets, SQL, Test)
* **СУБД:** PostgreSQL
* **Сборка:** CMake 3.16+

## Архитектура

Проект разделен на три слоя для обеспечения слабой связанности:
1. **data** — модели и репозиторий для работы с PostgreSQL и транзакциями.
2. **service** — бизнес-логика, кэширование, фильтрация и экспорт.
3. **ui** — графический интерфейс, взаимодействующий с данными только через сервисный слой.

## Установка и настройка

### 1. Зависимости (Ubuntu)
```
sudo apt update
sudo apt install build-essential cmake qtbase5-dev qtbase5-dev-tools libqt5sql5-psql postgresql
```

### 2. База данных
Создайте пользователя и две базы (основную и тестовую):
```
sudo -u postgres psql -c "CREATE ROLE adept_user LOGIN PASSWORD 'adept_pass';"
sudo -u postgres psql -c "CREATE DATABASE adept_tree OWNER adept_user;"
sudo -u postgres psql -c "CREATE DATABASE adept_tree_test OWNER adept_user;"
```
*Схема таблицы (файл `init-db.sql`) применяется автоматически при первом запуске.*

### 3. Переменные окружения
Создайте файл `env.sh` в корне проекта и примените его (`source env.sh`).
```
cat > env.sh <<'EOF'
export ADEPT_DB_NAME=adept_tree
export ADEPT_DB_HOST=localhost
export ADEPT_DB_PORT=5432
export ADEPT_DB_USER=adept_user
export ADEPT_DB_PASSWORD=adept_pass

export ADEPT_TEST_DB_NAME=adept_tree_test
export ADEPT_TEST_DB_HOST=localhost
export ADEPT_TEST_DB_PORT=5432
export ADEPT_TEST_DB_USER=adept_user
export ADEPT_TEST_DB_PASSWORD=adept_pass
EOF
source env.sh
```

## Сборка и запуск

**Сборка:**
```
cmake -S . -B build
cmake --build build -j
```

**Запуск приложения:**
```
./build/src/adept-tree
```

**Запуск тестов:**
```
ctest --test-dir build --output-on-failure
```

## Особенности работы

* **Экспорт/Импорт:** дерево сохраняется в JSON как плоский список объектов с полями `index`, `parentIndex`, `name`, `isLeaf` и `value`. Родители всегда экспортируются раньше потомков. При импорте текущее дерево полностью заменяется данными из файла.
* **Фильтр по значению:** ищет подстроку в строковом представлении числа (например, фильтр «12.3» найдет значение «12.34»).
* **Редактирование:** осуществляется двойным кликом по ячейке. Числовые значения хранятся и редактируются только у листьев.
